# Règles de scoring — La Ligue Enchantée

## Calcul automatique (fait par le site)

| Élément | Points | Condition |
|---------|--------|-----------|
| Note L'Équipe | 1-10 pts | Base du score |
| But (ATT / MIL) | +2 pts/but | Automatique |
| But (DEF) | +4 pts/but | Automatique |
| But (GK) | +10 pts/but | Automatique |
| Passe décisive | +1 pt/passe | Automatique |
| CSC | -2 pts/csc | Admin coche la case |
| Carton rouge | Note → 0 | Admin coche la case. Bonus buts/passes conservés |
| Penalty arrêté | +2 pts/pen | Admin coche la case (GK uniquement). Uniquement si le gardien a réellement arrêté le tir (pas un tir hors cadre) |
| Joueur non noté | 2 pts forfaitaires | Automatique |

## Géré manuellement par l'admin (exceptions)

| Élément | Points | Action admin |
|---------|--------|-------------|
| Penalty raté | -1 pt | Ajuster la note manuellement |
| Carton rouge annulé par la commission | Reste à 0 | Pas de changement (on garde la pénalité) |
| Tapis vert (sans feuille de match) | 5 pts gagnant / 4 pts perdant | Mettre ces notes manuellement à tous les joueurs du match |
| Tapis vert (avec feuille de match) | Titulaires gagnants 5 / perdants 4 / remplaçants 2 + bonus | Saisir les notes/bonus manuellement |
| Joueur non noté ayant joué < 45 min | 2 pts forfaitaires | Automatique (pas de note = forfait) |
| Joueur non noté ayant joué ≥ 45 min | 2 pts forfaitaires | Automatique (pas de note = forfait) |
